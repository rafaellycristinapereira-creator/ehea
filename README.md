# Dashboard Escolar - Colégio Futuro Saber

Este é um projeto de interface para um Dashboard Escolar desenvolvido com **HTML5** e **CSS3**, aplicando conceitos modernos de layout com Flexbox e CSS Grid.

## 🚀 Funcionalidades
- **Menu Lateral Adaptável:** Navegação organizada por seções.
- **Cards de Indicadores:** Visualização rápida de totais (Alunos, Professores, Livros, etc.).
- **Tabela de Alunos:** Lista com situação cadastral e layout responsivo.
- **Painel de Avisos & Eventos:** Comunicação e calendário integrado.
- **Design Responsivo:** Adaptado para telas de computadores, tablets e smartphones.

## 🛠️ Tecnologias Utilizadas
- HTML5 (Estrutura semântica)
- CSS3 (Flexbox, Grid, Variáveis e Estilização Avançada)
